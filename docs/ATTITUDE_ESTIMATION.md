## 1. 传感器与可达性边界（先立边界，再谈算法）

### 1.1 飞行中加计与姿态无关（严格）
唯一非重力力是沿机体 z 的推力 ⇒
`f_meas = (T/M)·e_z + R^T(ω̇×r + ω×(ω×r))`，**整个式子不含 R**。
* 加计在**悬停/低推力**时才是倾角仪（经典 AHRS）✓；在**推力主导的剧烈自旋**（本故障）里**不提供倾角** ✗。
* 杆臂项只给 `|ω|` 的**幅值**信息，不给世界系方向。

### 1.2 多轴饱和的"非阿贝尔"污染
单步内"绕机体 z 的旋转不改变推力轴"成立（`ΔR e_z = e_z`），但**旋转序列不可交换** ⇒ 多个轴的截断误差累积后
仍会把推力轴带偏。**实测**（同一抽签、开环、纯 INS 用限幅陀螺，前 1.5 s 倾角误差）：

| 陀螺量程 | 平均饱和轴数 | **限幅陀螺** | （真值速率对照） |
|---|---|---|---|
| 2000 dps | 0.29 | **57.4°** ✗ | 5.04° |
| 2500 dps | 0.22 | 36.0° ✗ | 5.04° |
| 3000 dps | 0.14 | **7.8°** ✓ | 5.04° |
| 4000 dps | 0.04 | 5.1° ✓（全程 42.4° ✗） | 5.04° |
| **6000 dps** | **0.00** | **5.1°（全程 5.29°）** ✓✓ | 5.04° |

⇒ **"这台故障需要多宽的陀螺"≈ 6000 dps**（自旋 ~2464 dps，闭环中还会上冲）——这是传感选型的直接结论。

### 1.3 单轴（dps2000 主流工况）
实测饱和帧里 **1 轴 ≈ 57%、2 轴 28%、3 轴 ≈ 14%**；1 轴帧误差 **0.68 rad/s** ✓，2 轴 2.62 ✗，3 轴 6.09 ✗。
**2/3 轴帧绝大多数出现在饱和开始 20 帧之后**（失稳尾段），按项目判断**先排除**；**dps2000 的主攻对象是
"单轴 —— yaw（偶发 roll，实测 roll 饱和占比最高 10.2%，因为控制器为对抗不对称力矩在 roll 上打得很狠）"**。

## 2. 观测器链路（三段式）

### 2.1 代数前端（把饱和轴"算"出来）
加计杆臂项给出可测残差 `s = a_meas − (T/M)e_z = ω̇×r + ω×(ω×r)`；对**被限幅**的轴：
```
|ω_i| = sqrt(|s| / k) ,  k = |r_perp| ,  符号由限幅值给出
```
* `T/M` **由指令**经辨识的 `g_T` 与执行器滞后 `tau` 推出（`gpd_me.priors.tom_from_command`），**绝不用仿真真值**；
* 未饱和轴直接使用陀螺读数（**逐位相等**已验：dps2000 数据上 `|net − clip| = 0.000 rad/s` 于 93% 未饱和样本）；
* **可辨识性否决**：扫描标定在"切向项未钉住尺度"时是**尺度简并**的 ⇒ `k` 只在可辨识处采用，否则**退回纯限幅**。

### 2.2 INS（姿态积分）
`R ← R @ exp(ω dt)`（机体速率、右乘、因果）。
* **时间戳对齐**：测量（或前推）半步对齐用 **惯性系角速度** `ω_world = R @ ω_body`（推力轴体固）；
* **固有残差**：以真值速率积分仍有 **~5°**（同一抽签 5.04°）——已排除积分阶数/相位（插值真值最优对齐在 α≈1.00）/
  执行器延迟/杠杆臂四种解释，属**仿真器内部格式与显式积分器之间的离散化差异**，如实记录为**未解项**。

### 2.3 倾角观测器（`gpd_me/tilt.py`，30 行、零训练、不需要外部姿态）
```
R[:,2] = (a_i + g e_z)/|a_i + g e_z| ,  a_i = d(vel)/dt
互补融合（在角度空间步进）:  step = (dt/(τ+dt)) · w(|t|) · θ
```
设计要点（每条都有实验依据）：
1. **角度空间步进**（`α·θ`，不是归一化线性混合）：后者实际转角 ≈ `α·sinθ` ⇒ 90/150/170° 时增益塌到 0.64/0.19/0.06，
   **恰在大误差区失效**（外部审计指出并修正）；
2. **反极性分支**：θ→180° 时旧实现直接返回未修正 ⇒ 完全翻转的姿态永远救不回；
3. **推力加权**：测量角误差 ∝ 1/|t| ⇒ 按 `w=|t|/(|t|+c)` 加权（硬门限 0.5 m/s² 会接受 45° 误差）；
4. **时间戳对齐** `align_s`（默认 dt/2；实测最优 ~10 ms，属可由飞行日志标定的时序常数）；
5. **只修 z 轴**：**不给航向**（不做任何绕推力轴的旋转）；副作用是平行移动会缓慢改变航向（已如实写明）。

**测量自身的精度**（dps2000、开环）：1 轴饱和 4.8–6.3° ✓；**2–3 轴饱和 41–54°** ✗（来源未查明：
杠杆臂（回归 `|r_eff|=0.62 mm` 且残差不变）与时间戳（中点对齐只到 41–46°）两个解释均被**定量否证**）。

### 2.4 三个通道各给哪些自由度
| 自由度 | 陀螺（不饱和时） | 加计 | 速度通道 | 磁力计 |
|---|---|---|---|---|
| 倾角（2） | ✓ | 仅悬停 ✓ | **✓（本故障唯一可用）** | ✗ |
| 航向（1） | ✓ | ✗ | **✗** | **✓** |

## 3. 姿态估计器（网络，`gpd_me/e2e.py`）

### 3.1 结构（残差式、因果、可部署）
```
w_hat = w_alg + sat ⊙ δ(fast head)          δ 的头零初始化 ⇒ 未饱和轴 = 精确陀螺
```
* **逐帧精细特征 29 维**：`s(3) | |s| | gyro(3) | sat(3) | 指令推力(4) | T/M | 9 个辨识先验 | |gyro| | w_alg(3) | 偏航模型 w_z_model`
* **2 s 粗摘要 17 维**（5 个聚合量 + 3 个逐轴饱和占比 + 9 先验）→ 慢头；
* **时序**：2 层 GRU（hidden 256），**96 帧（480 ms）滑动窗、每步重算**（⇒ 有效记忆 = 480 ms，见 §3.4 的改进方向）；
* **规模**：**937,737 参数 = 3663 KB fp32 / 916 KB int8**。

### 3.2 损失与训练配方（当前默认）
`L_rate`（仅饱和窗）＋`L_att`（INS 滚动）＋`L_phys`（代数残差）＋`L_torque`（偏航 ARX，**起点尖峰按掩码剔除**）
＋`L_spec`＋`L_bias`＋`L_inband`（**误差的 <10 Hz 幅度**，直击闭环约束量）。
* **`L_prior`（特权标签 `r/g_T` 监督慢头）默认关闭**，慢头默认停用（`--use_slow` 可开）；
  ⇒ **训练所用的量与部署输出必须一致**（今日已因不一致吃过两次亏 ✗）。
* 数据：`results/dr_1e7_v3`（12 档混合，5000 分片）/ `results/dr_dps2000`（2000 轮、400 万步）；
* 先验全部来自**可测量**：偏航 ARX 与辨识机动幅值均已改为读**未饱和段实测陀螺**（此前用 `omega_true` ✗）。

### 3.3 部署形态与时延（诚实口径）
| 指标 | 数值 |
|---|---|
| 参数 / 体积 | 937,737；3663 KB fp32；**916 KB int8** ✓ |
| 网络前向 | CPU 6.3 ms / **GPU 1.19 ms** |
| **`NetRate.step` 端到端** | CPU **23.57 ms** ✗ / **GPU 5.76 ms**（超 5 ms 预算 15%，其余 ~4.5 ms 是 Python 预处理）|

### 3.4 三条硬性一致性要求（用血换来的）
1. **观测约定**：dims 7:11 = `last_action[0]` **广播过掩码**（师兄 `MetaShutDown7.py:174`）；**所有**消费者必须走
   同一个 `deploy_obs`（已把 E4/Gazebo 两处手写拼装删掉，并在 `test_obs_convention.py` 里加了**调用点断言**）。
2. **时间对齐**：半步对齐用惯性系角速度；训练/部署同一套 `align_s`。
3. **特征语义**：任何新特征（如相位计数器）训练与部署必须同定义、同上限。

## 4. 实验与结论（只列当前有效）

### 4.1 估计精度（标准二口径）
| 口径 | 数值 |
|---|---|
| `network/clip`（dps ≤ 1000，官方脚本） | **0.204**（目标 ≤0.10；此前版本 v6→0.393、v10→0.205） |
| 分档 | **150 dps 0.09 ✓ / 700 dps 0.10 ✓**；六档 ≤0.20；最差 1000 dps 0.32 ✗ |
| oracle（喂**真值** `k`，明确不可部署） | 0.32 ⇒ **网络优于 oracle** |
| dps2000 专属模型 v13 | 0.334（分母效应：友好运行点上削顶本身更好） |

> **口径必须写明**：同一模型在"任意饱和窗 / 困难区"×"先均值再比值 / 逐窗比值（均值/中位）"下可给出
> **0.09–0.37**。建议主报：`dps≤1000、先均值再比值 = 0.204`，并附 150/700 dps 档 0.09/0.10。

### 4.2 消融（说明"代数在环"是核心设计）
* 去掉代数特征（`--mode noalg`）：**+11%** 误差 ⇒ 单点最强设计 ✓；
* `L_prior`：**有害**（去掉后 window lag 6.47 vs 6.60、验收 0.274 vs 0.293）⇒ 默认关闭 ✓；
* 容量/窗口/物理特征的收益递减：0.393→0.246→0.227→0.212→0.205（四版之后进入平台期）。

### 4.3 `k` 是速率误差的主因（oracle-k 判决）
dps2000、纯 IMU、12 抽签：

| k | net 守住 | tilt | **rate_err** |
|---|---|---|---|
| 在线辨识 0.94 cm | 5/12 | 54.2° | **4.38** |
| **真值 1.30 cm**（不可部署） | 3/12 | **31.5°** | **1.16**（优于削顶 1.81） |

⇒ **网络的速率恢复能力真实**（4.38→1.16，**3.8×**）✓；**但闭环守住不变**（n=12 噪声）⇒ 闭环缺的是"**倾角**"，
不是"更准的速率"。**`k` 的纯 IMU 辨识在 dps2000 下退化**（饱和样本仅 4.8%，扫描无数据；联合拟合更差），
列为**开放问题**（其收益上限已被 oracle 量化为 3.8×）。

### 4.4 误差结构：相位 × 饱和轴数（dps2000）
| (距饱和起点, 轴数) | 样本 | \|误差\| 均值 |
|---|---|---|
| (0, 1) | 1612 | 0.96 |
| (0, 2) | 531 | 6.12 |
| (0, 3) | 250 | 11.63 |
| (3 = 已深, 1) | 10964 | **0.68** ✓ |
| (3, 2) | 5408 | 2.62 |
| (3, 3) | 2768 | 6.09 |

⇒ ①**轴数**是主因（1→3 轴约 10 倍）；②**起始相位**在多轴时额外 ~2× 惩罚（(0,2) 6.12 vs (2,2) 2.78）。
**机制**：起始步的差分 `ω̇` 是阶跃哑值 ⇒ 代数中的 `ω̇×r` 被污染（与"`L_torque` 起点尖峰占目标 ~95%"一致）。
**注意**：2/3 轴样本多在失稳尾段（§1.3），按项目判断排除；**主攻单轴 + 起始相位**。

### 4.5 倾角观测器的闭环收益（允许平动源链路）
* **12 抽签配对**（dps1000 混合）：**p = 0.0010**、**11/12 改善**、平均 **+323 步**、前 300 步倾角 **52.4°→26.7°**；
* **速度退化臂**（σ_v=0.05 m/s + 0.05 s 滤波）：仍 **p = 0.0342、11/12** ✓ ⇒ **机制不是仿真假象**；
* **真值行**：13/16 → **22/24**（16 抽签口径）；
* **dps2000**：`clipped` 3/12 → **24/24**、`net` 4/12 → 18/24（12 抽签）；24 抽签口径下
  **truth 24/24、clipped 24/24（p=nan 零差异）、net 18/24（p=0.005）**。

### 4.6 绑定量：是**倾角**，不是速率、不是航向（双向干预）
| 运行点 | `oracle-rollpitch`（真值倾角+估计航向） | `oracle-yaw`（真值航向+估计倾角） |
|---|---|---|
| dps1000 | **1000/1000 全程守住** ✓ | 468/960/288/225（常差于基线）✗ |
| dps2000 | **+34.7 步、3 胜 0 负** ✓ | +1.0 步、5 负 ✗ |

另有旁证：观测器让**真值行**的倾角 *RMS* 变差（2.9°→14.4°）却让守住率**变高**（13/16→16/16）
⇒ **绑定量是倾角误差的"偏置"，而非幅值**（与容忍度曲线一致：白噪声 σ=2 尚可、常值偏置 +1 rad/s 致命）。

   合成侧的主因已定位为**奖励实现漏洞**（奖励落在估计空间，已修：修后标称全程 4/4 ✓、中档污染 0/4→4/4 ✓）。
2. **开环精度 ↔ 闭环守住率反相关（五例）**：速率误差改善 3.8× 而守住略降；v13 开环全面更优却 11/24 vs 12 的
   18/24；符号/幅值/滞后三假设均被否证 ⇒ **机制未识别**。
3. **~5° 的 INS 固有残差**（以真值速率积分亦有）——四种解释已排除，属仿真离散化差异。
4. **倾角测量在 2–3 轴饱和时 41–54°** ——杠杆臂与时间戳解释均被定量否证。
5. **Gazebo**：端口已修（工厂插件需正确 `DISPLAY=:0`；`--substeps` 自动检测按**墙钟**测率 ⇒ 负载下曾变成

   同点 24/24），且**网络行受 Python 预处理限制跑不到设计节拍**（`NetRate.step` GPU 5.76 ms）。

## 5. 结论与可选路线

**结论**（按链路分开）：
* **允许平动源（=师兄原有约定）**：**dps2000 下标准一达成（24/24 = 真值，逐抽签零差异）** ✓；贡献物是**倾角
  观测器**（零训练、不用外部姿态、p=0.001、速度退化仍 p=0.034）✓。
* **纯 IMU**：dps2000 下标准一未达成（18/48 vs 真值 48/48）✗；根因是**偏航饱和污染倾角**（非阿贝尔），
  算法无解 ⇒ 需要 **① 更宽量程陀螺（≈6000 dps 零饱和）** 或 **② 先把 `k` 辨识做准**（其上限已被 oracle 量化
  为 3.8× 速率改善，但闭环仍缺倾角）。
* **标准二**：网络相对普通方法 **4.9×**（0.204），150/700 dps 档 **0.09/0.10** ✓；瓶颈是 `k` 的在线辨识。
* **标准三**：体积达标（916 KB int8）；端到端时延 GPU 5.76 ms（需一次向量化/量化优化进入 5 ms）。
* **标准四**：无特权输入（“先验全部来自可测量”“观测只用可测量”均已逐条修正并有断言）。

**可选路线**：
1. **A（推荐，改动最小）**：接受平动源 ⇒ 交付"倾角观测器 + 削顶/估计器"，标准一在 dps2000 达标（100% 真值）；
2. **B**：换宽量程陀螺（≥6000 dps）⇒ 纯 IMU 达标（零饱和，倾角 = 真值水平）；
3. **C**：继续攻 `k`（收益上限 3.8× 速率）与"估计器在环"的**从零训练**（而非热身后微调）。
