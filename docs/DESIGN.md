# 设计说明

## 1. 物理：IMU 与杠杆臂

IMU 固连在机体系偏移 `r` 处。机体系输出：

```
陀螺:  ω_m = clip( (ω + b_g) ⊙ κ_g + n_g , ±ω_max )        ω_max = 1000…4000 dps, κ_g 为刻度误差
加计:  a_m = (ΣT/M)·ê_z + ω̇×r + ω×(ω×r) + b_a + n_a
```

- 第一项就是学长环境里的 `last_acc = ΣT/M`，恒沿体 z；
- **重力在比力里精确抵消**，所以自由飞行时加计**不含姿态信息**——本机上陀螺是唯一姿态源（除非有动捕/磁力仪）；
- 因此加计在这里本质是"**杠杆臂角速度传感器**"：稳态 `s = a_m − (ΣT/M)ê_z = ω×(ω×r) = −|ω|²·r⊥`，
  即 `|s| = |ω|²·|r⊥|`。这是超量程重建的全部信息源。

已验证：加计模型 vs pybullet 有限差分 **0.093 m/s²**（信号 12.6）；`(T/M)` vs `Rᵀ(dv/dt+g)` **0.0026 m/s²**。

## 2. 辨识：需要的先验只有 9 个数，且全部来自飞行数据

| 先验 | 来源 | 说明 |
|---|---|---|
| `r` (3) | 量程内样本加权 LS（切向项开启）；量程内样本不够信息量时改用一维尺度扫描 | 沿自旋轴的分量不可观测，但它对物理无贡献（被 `ωωᵀ−\|ω\|²I` 零化）；路由按**信息量**选，不按可用性 |
| `g_T = c_T/M` | 正常段（失效前）悬停段：`a_z = T/M` 且 `Σu_alive = M g` | 本环境指令即牛顿，故 `g_T = 1/M` |
| `G = K_M c_T / c` | 量程内偏航通道 ARX 的 DC 增益 | |
| `T = J_z / c` | 同一 ARX 的主极点 | |
| `τ` | 正常段：一维扫描拟合转速一阶滞后，**每候选 τ 闭式解出幅值** | 只拟合"形状"，因此 g_T 的误差不会把 τ 拉偏（未做此解耦时 τ 误差中位 −89%） |
| `k = \|r⊥\|` | 取辨识过程（一维扫描）**自标定出的标量** | 用 `‖r‖` 会高估尺度、把饱和轴反解成 0（比削顶更差）；改成"逐样本按当前自旋方向投影"也试过并被**删回**——它会直接继承 `r̂` 的 20–50% 误差（实测按航次滞后 4.77 标量 vs 5.27 逐样本 vs 5.04 混合） |

### 2.1 推力重建必须只用指令（评审 BLOCKER 3）

`s` 与特征里的 `T/M` **绝不能用仿真真值**，只能这样算：

```
u_alive(t) → 一拍输入延迟 → 转速一阶滞后 n ← n_t + (n−n_t)·exp(−dt/τ) → T/M = g_T·Σ n²
```

其中 `τ` 与 `g_T` 都是辨识出来的。三条实测教训：

1. 被控对象在第 k 拍使用第 **k−1** 拍下发的指令（`step()` 内 latch、下一步才生效）。忽略这一拍，
   `T/M` 重建误差 0.1–1.75 m/s²；建模后 **0.001–0.006 m/s²**。
2. 拟合 τ 时若在段内重启积分器，会自己造出一个长度 ≈ 3τ 的爬升瞬态，把 τ 系统性地拉向网格下界。
   必须从 t=0 积分、只在稳态窗口上打分。
3. 固定幅值拟合时，`g_T` 偏低会被"更快的 τ"补偿（高频增益更大）→ 必须每候选 τ 闭式解幅值。

`G`、`T` 是**唯一进入偏航力矩关系** `T·dω_z/dt + ω_z = G·Σ(±u)` 的组合，因此**不需要绝对的 `K_M`、`J_z`**
——这正是"先验可以从数据里估出来"的关键。正常段还包含一次**两段式开环偏航辨识机动**
（先给小差分估增益，再按开环 profile 打到 **0.55×量程**——比原来的 0.3×量程给出更强
`|s| = k|ω|²` 信号；低量程段即使这样也拿不到量程内高转速样本，那是量程本身的物理限制）。

## 3. 网络：端到端，但把代数放在系统内部而不是让它去学

```
w_hat = w_alg(s, gyro, sat, k̂)  +  sat ⊙ δ(GRU(48 帧 × 28 维))
       └── 系统内部按可测量算出的闭式解 ──┘   └── 只修正饱和轴 ──┘
```

特征 28 维：`s(0:3) | |s|(3) | gyro(4:7) | sat(7:10) | u(10:14) | T/M(14) | priors(15:24) | |gyro|(24) | w_alg(25:28)`
—— 读取陀螺一律用导出的 `GYRO_SLICE`（历史上插特征导致过一次索引错位）。

- **特征只用可测量**：残差 `s`、`|s|`、原始陀螺、饱和掩码、推力指令、`T/M`、**9 维先验**、`|gyro|`、`w_alg`；
  `w_alg` 不是特权信息——任何真机都能从同样的量算出来；
- **物理参数化输出**：未饱和轴就是陀螺的精确测量，网络只对**饱和轴**输出修正，且最后一层零初始化 →
  训练从物理量出发；
- **快/慢双时间尺度**：快头出 `ω̂`，慢头（2 s 因果汇总）出参数修正 `Δr, Δg_T, ΔG, ΔT`；
- **可微 INS**：用 `ω̂` 逐步旋转姿态（Rodrigues，逐窗 `dt`），损失直接罚姿态误差——因为闭环实验证明
  **决定生死的是姿态通道**，不是速率输入本身。

### 六项损失

| 项 | 权重 | 需要标签 | 作用 |
|---|---|---|---|
| `L_rate` | 1 | 是（仿真） | 饱和帧上的 Huber 速率误差 |
| `L_bias` | 1 | 是 | **窗口内时间平均误差**——专门罚"稳定滞后"（常数偏差会线性积分成姿态误差） |
| `L_att` | 0.5 | 是 | 可微 INS 的倾斜 + 0.2×全姿态误差 |
| `L_phys` | 0.3 | 否 | 加计残差一致性：`a_m − (T/M)ê_z − ω̂̇×r̂ − ω̂×(ω̂×r̂)` |
| `L_torque` | 0.1 | 否 | 偏航通道：`T·ω̂̇_z + ω̂_z − G·Σ(±u)`；`G/T` 未辨识的航次**整段跳过**（否则退化成 `huber(w_z/10)` 这种非法约束） |
| `L_spec` | 0.05 | 否 | 频域正则（实测速率 95% 功率在 7.1 Hz 以下）；>10 Hz 的掩码按**每个窗口自己的 dt** 取 |

> 原第七项 `L_anchor`（量程内 `‖ω̂−陀螺‖`）在物理参数化下**结构性恒为零**——未饱和轴本来就等于陀螺测量。
> 已删除，其意图（不许偏离辨识出的物理量）改由**慢头修正量的硬 bound**（`tanh`，Δr ≤ 2 cm 等）保证。

无标签的三项（`L_phys` / `L_torque` / `L_spec`）使真机上的在线自适应成为可能。

## 4. 指标定义（必须区分，否则会自欺）

| 指标 | 定义 | 为什么 |
|---|---|---|
| **按航次滞后** | 各航次内 `‖mean_t(ω̂−ω)‖` 再对航次取平均 | **这才是会积分成姿态误差的量**；全局均值会让不同航次的正负滞后互相抵消 |
| 全局偏差 / 抖动 | 所有饱和帧误差的均值模 / 去均值后的模均值 | 只作辅助 |
| 倾斜@60 ms | 从真值姿态出发、用 ω̂ 展开 60 ms 后的倾斜误差 | 240 ms 窗口在高转速下被自旋幅值支配，不可用 |
| 按量程分层 | 每个量程单独报 | 把 100 dps 与 6000 dps 平均在一起没有意义 |

## 5. 设计评审中被否掉/修正的做法（记录以免重犯）

1. 曾让 GRU 从零学"开平方 + 闭式反解"→ 改为把 `w_alg` 放进系统内部，网络只学残差；
2. 曾用无约束 3 维输出 → 改为物理参数化（只修正饱和轴）；
3. 曾用异方差 NLL → 不适定，改 Huber；
4. 曾用 120/240 ms 作为倾斜窗口 → 高转速下不可用，主指标改为按航次滞后；
5. 曾把先验当外部常量 → 改为辨识层 + 慢头修正；
6. 曾把估计值只喂控制器速率输入 → 闭环对照证明必须**同时**驱动 INS。
