# 设计说明

## 1. 物理：IMU 与杠杆臂

IMU 固连在机体系偏移 `r` 处。机体系输出：

```
陀螺:  ω_m = clip( (ω + b_g) ⊙ κ_g + n_g , ±ω_max )        ω_max = 1000…4000 dps, κ_g 为刻度误差
加计:  a_m = (ΣT/M)·ê_z + ω̇×r + ω×(ω×r) + b_a + n_a
```

- 第一项就是学长环境里的 `last_acc = ΣT/M`，恒沿体 z；
- **重力在比力里精确抵消**，所以自由飞行时加计**不含姿态信息**——本机上陀螺是唯一姿态源（除非有动捕/磁力仪）；
- 因此加计在这里本质是"**杠杆臂角速度传感器**"：稳态 `s = a_m − (ΣT/M)ê_z = ω×(ω×r) = −|ω|²·r⊥`，
  即 `|s| = |ω|²·|r⊥|`。这是超量程重建的全部信息源。

已验证：加计模型 vs pybullet 有限差分 **0.093 m/s²**（信号 12.6）；`(T/M)` vs `Rᵀ(dv/dt+g)` **0.0026 m/s²**。

## 2. 辨识：需要的先验只有 7 个数，且全部来自飞行数据

| 先验 | 来源 | 说明 |
|---|---|---|
| `r` (3) | 量程内样本线性 LS（模型对 `r` 线性）；否则一维尺度扫描 | 沿自旋轴的分量不可观测，但它对物理无贡献（被 `ωωᵀ−\|ω\|²I` 零化） |
| `g_T = c_T/M` | 悬停配平：`Σu_alive = M g` | 本环境指令即牛顿，故 `g_T = 1/M` |
| `G = K_M c_T / c` | 量程内偏航通道 ARX 的 DC 增益 | |
| `T = J_z / c` | 同一 ARX 的主极点 | |

`G`、`T` 是**唯一进入偏航力矩关系** `T·dω_z/dt + ω_z = G·Σ(±u)` 的组合，因此**不需要绝对的 `K_M`、`J_z`**
——这正是"先验可以从数据里估出来"的关键。正常段还包含一次**两段式开环偏航辨识机动**
（先给小差分估增益，再按开环 profile 打到 ~30% 量程），保证每种量程都有量程内样本。

## 3. 网络：端到端，但把代数放在系统内部而不是让它去学

```
w_hat = w_alg(s, gyro, sat, k̂)  +  sat ⊙ δ(GRU(48 帧 × 21 维))
       └── 系统内部按可测量算出的闭式解 ──┘   └── 只修正饱和轴 ──┘
```

- **特征只用可测量**：残差 `s`、`|s|`、原始陀螺、饱和掩码、推力指令、`T/M`、7 维先验、`|gyro|`、`w_alg`；
  `w_alg` 不是特权信息——任何真机都能从同样的量算出来；
- **物理参数化输出**：未饱和轴就是陀螺的精确测量，网络只对**饱和轴**输出修正，且最后一层零初始化 →
  训练从物理量出发；
- **快/慢双时间尺度**：快头出 `ω̂`，慢头（2 s 因果汇总）出参数修正 `Δr, Δg_T, ΔG, ΔT`；
- **可微 INS**：用 `ω̂` 逐步旋转姿态（Rodrigues，逐窗 `dt`），损失直接罚姿态误差——因为闭环实验证明
  **决定生死的是姿态通道**，不是速率输入本身。

### 七项损失

| 项 | 权重 | 需要标签 | 作用 |
|---|---|---|---|
| `L_rate` | 1 | 是（仿真） | 饱和帧上的 Huber 速率误差 |
| `L_bias` | 1 | 是 | **窗口内时间平均误差**——专门罚"稳定滞后"（常数偏差会线性积分成姿态误差） |
| `L_att` | 0.5 | 是 | 可微 INS 的倾斜 + 0.2×全姿态误差 |
| `L_phys` | 0.3 | 否 | 加计残差一致性：`a_m − (T/M)ê_z − ω̂̇×r̂ − ω̂×(ω̂×r̂)` |
| `L_torque` | 0.1 | 否 | 偏航通道：`T·ω̂̇_z + ω̂_z − G·Σ(±u)` |
| `L_anchor` | 0.3 | 否 | 量程内 `\|ω̂ − 陀螺\|`（**注意：在默认模式下结构性恒零，见评审**） |
| `L_spec` | 0.05 | 否 | 频域正则（实测速率 95% 功率在 7.1 Hz 以下） |

无标签的四项使真机上的在线自适应成为可能。

## 4. 指标定义（必须区分，否则会自欺）

| 指标 | 定义 | 为什么 |
|---|---|---|
| **按航次滞后** | 各航次内 `‖mean_t(ω̂−ω)‖` 再对航次取平均 | **这才是会积分成姿态误差的量**；全局均值会让不同航次的正负滞后互相抵消 |
| 全局偏差 / 抖动 | 所有饱和帧误差的均值模 / 去均值后的模均值 | 只作辅助 |
| 倾斜@60 ms | 从真值姿态出发、用 ω̂ 展开 60 ms 后的倾斜误差 | 240 ms 窗口在高转速下被自旋幅值支配，不可用 |
| 按量程分层 | 每个量程单独报 | 把 100 dps 与 6000 dps 平均在一起没有意义 |

## 5. 设计评审中被否掉/修正的做法（记录以免重犯）

1. 曾让 GRU 从零学"开平方 + 闭式反解"→ 改为把 `w_alg` 放进系统内部，网络只学残差；
2. 曾用无约束 3 维输出 → 改为物理参数化（只修正饱和轴）；
3. 曾用异方差 NLL → 不适定，改 Huber；
4. 曾用 120/240 ms 作为倾斜窗口 → 高转速下不可用，主指标改为按航次滞后；
5. 曾把先验当外部常量 → 改为辨识层 + 慢头修正；
6. 曾把估计值只喂控制器速率输入 → 闭环对照证明必须**同时**驱动 INS。
